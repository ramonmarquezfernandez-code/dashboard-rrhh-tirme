Interfaz interactiva para probar los endpoints de la API

📖 Swagger UI (Documentación Interactiva) 🏠 API Inicio

GET Listado de Partes

/api/partes?page=1&per_page=20

Obtiene un listado paginado de todos los partes de horas registrados.

GET Partes por Empleado

/api/partes/empleado/{pernr}

Obtiene todos los partes de horas de un empleado específico.

GET Resumen por Departamento

/api/partes/resumen-departamento?anio=2026

Resumen de horas extras agrupadas por departamento.

GET Resumen por Trabajador

/api/partes/resumen-trabajador?anio=2026

Resumen de horas extras agrupadas por trabajador.

GET Horas Extras Comité

/api/partes/comite?anio=2026

Resumen de horas extras para el comité.
